# audio/

Drop a file named **`theme.mp3`** here and it becomes the background music.

If there's no file, `js/fx.js` generates a soft four-chord lullaby in the browser
with the Web Audio API instead — so the music button always does something,
and there's no licensing or file size to worry about.

Change the filename in `content/config.json` → `music.file` if you want.
